## 📌 About the Project

Welcome to the **Mobile Application Development Lab Repository**.

This repository contains various Android applications and practical exercises developed during the Mobile Application Lab. The projects demonstrate fundamental concepts of Android development, including user interface design, activity lifecycle, event handling, input validation, and application functionality.

All applications are developed using **Java programming language** with **XML-based UI design** in **Android Studio**.

# 🧪 Laboratory Experiments

## 🔹 Experiment 3: Signup Validation Application

### Description
A simple Android application that validates user registration details.

### Features:
✅ Username validation  
✅ Password validation  
✅ Confirm password verification  
✅ Error message display  
✅ Successful registration message  

### Concepts Covered:
- EditText input handling
- Button click events
- Conditional statements
- Activity creation
- UI interaction
